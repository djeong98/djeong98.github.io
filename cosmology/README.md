# ASTRO/PHYS 545 — course site

Static pages for `djeong98.github.io/cosmology/`. No Jekyll: the parent
repository has `.nojekyll`, so what is committed is what is served.

## Files

| | |
|---|---|
| `*.md` | sources. Edit these, not the HTML. |
| `template.html` | pandoc template: header, nav, footer, MathJax. |
| `assets/style.css` | palette and fonts taken from `../assets/css/style.css`, typography set for long documents. |
| `assets/mathjax-config.js` | delimiters. Kept out of the template because `$` collides with pandoc template syntax. |
| `build.sh` | rebuilds all five pages. |
| `*.html` | generated. Committed so the site works without a build step. |

## Rebuilding

    sh build.sh

Requires pandoc. Each page's `<h1>` becomes its browser title, and the
nav highlights the current page from a metadata flag set in `build.sh`.

## Notes

- `syllabus.md` is the web copy of the syllabus. The detailed learning
  objectives live in `topics.md`, not in the syllabus.
- The top-level pages of the parent repo are generated by
  `scripts/build.mjs` from `content/wordpress-pages.json`. Do not hand-edit
  them. To point the Teaching page at this site rather than at
  `sites.psu.edu/cosmology`, change the entry in that JSON and re-run the
  parent build.
- Placeholders to fill before the term: TA name and hours, Canvas link,
  and the term line at the top of the syllabus.
